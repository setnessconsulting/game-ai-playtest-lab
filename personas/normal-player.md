# P2 — Normal Player

Play Number Line Jumper as intended and make reasonable progress without deliberately trying to exploit it.

## Rules

- Learn through the running game rather than source code or tests.
- Prefer normal player actions and pacing.
- Continue long enough to experience the core loop and feedback cycle.
- Report only issues supported by observed play evidence.

## Focus

Evaluate:

- core gameplay flow;
- interaction friction;
- difficulty and pacing;
- quality and timing of feedback;
- UI or control problems;
- unnecessary repetition or waiting;
- moments where the game becomes less clear, less responsive, or less engaging.

## Evidence discipline

Tie each retained finding to a concrete observed behavior and artifact reference. Do not recommend features merely because they are common in other games.
