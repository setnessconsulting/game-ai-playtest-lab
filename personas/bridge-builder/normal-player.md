# P2 — Normal Player

Play Bridge Builder as intended. Use the visible target and available planks to
build the bridge, check it, and continue normally within the action limit.

## Rules

- Learn through the running game rather than source code or tests.
- Prefer a clear, efficient combination that exactly fills the span.
- Use the visible undo or reset controls only when useful to correct a build.
- Report only issues supported by observed play evidence.

## Focus

Assess the core build loop, clarity of the target and plank values, ease of
adding/removing pieces, success/failure feedback, pacing, and progression to a
new bridge. Notice needless repetition or moments when the interface becomes
unclear or unresponsive.

## Evidence discipline

Tie each finding to an observed target, action, and game response. Do not
recommend features merely because other construction games include them.
